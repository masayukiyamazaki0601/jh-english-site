📖 英文法 解説

学年ごとにタブで切り替えて、学びたい単元を選べます

✅

be動詞

am, are, is の使い方をマスター。肯定文・否定文・疑問文を学びます。

中学1年 🏃

一般動詞

run, eat, playなど 動作を表す動詞の使い方。三人称単数の前に基礎を固めよう。

中学1年 ❓

疑問文・否定文

be動詞と一般動詞、それぞれの疑問文と否定文の作り方を比較しながら学びます。

中学1年 🤔

疑問詞

what, who, where, when, why, how を使った疑問文。下線部を尋ねる問題も対応。

中学1年 ❗

命令文

「〜しなさい」「〜してはいけません」命令文・禁止文をマスター。

中学1年 👤

三人称単数現在

he, she, it のとき動詞に s がつくルール。三単現のs を完全理解。

中学1年 🔄

現在進行形

「〜している」進行形の形と意味。be動詞 + 動詞のing 形を学びます。

中学1年 💪

can（助動詞）

「〜できる」の表現。canの肯定文・否定文・疑問文をマスター。

中学1年 ⏪

一般動詞の過去形

動詞の過去形（ed形・不規則変化）。過去の出来事を英語で言えるように。

中学1年 🔢

名詞の複数形

複数形のルール（s, es, 不規則変化）。a/an の使い分けも。

中学1年 👥

代名詞

I, my, me, mine など人称代名詞の変化表。主格・所有格・目的格・所有代名詞。

中学1年 📛

冠詞（a, an, the）

aとanの使い分け、theの使い方、冠詞をつけない場合のルールまで。英語の基本を固めよう。

中学1年 🔢

数量表現

many/much, some/any, a few/a littleの使い分け。可算名詞と不可算名詞の違いも学べる。

中学1年 ✅⏪

be動詞の過去形

was, were の使い方。過去の状態を表す表現をマスター。

中学2年 🔄⏪

過去進行形

「〜していた」過去のある時点で進行中の動作。was/were + doing。

中学2年 🔮

未来形

will と be going to の違い。未来の表現を使い分けられるように。

中学2年 🏊

動名詞

動詞のing形が名詞の役割に。〜すること。不定詞との違いも解説。

中学2年 🎯

不定詞（基本）

to + 動詞の原形。名詞的用法・副詞的用法・形容詞的用法をマスター。

中学2年 ⚡

助動詞

must, have to, may, should など便利な助動詞をまとめて学習。

中学2年 📊

比較

比較級・最上級・原級を使った比較表現。er/est, more/most の使い分け。

中学2年 📍

there is 構文

「〜がある/いる」を表す there is/are 構文。疑問文・否定文も。

中学2年 📍

前置詞

in, on, at, for, since, to, from など位置・時間・方向の前置詞を一覧でマスター。

中学2年 🔗

接続詞

and, but, because, when, if, that など文と文をつなぐ接続詞。

中学2年 🔄

受け身（受動態）

「〜される」受け身の形。be動詞 + 過去分詞。能動態からの書き換えも。

中学2年 📌

現在完了（継続）

have/has + 過去分詞。継続用法「ずっと〜している」をマスター。

中学3年 ✈️

現在完了（経験）

「〜したことがある」経験用法。ever/never の使い方も。

中学3年 ✅

現在完了（完了・結果）

「ちょうど〜したところ」「もう〜した」完了・結果用法。already, just, yet。

中学3年 🔄📌

現在完了進行形

have/has been + doing。「ずっと〜し続けている」強調表現。

中学3年 🎯2️⃣

不定詞（応用）

It ... for ... to〜, 疑問詞+不定詞, ask/tell + to など応用表現。

中学3年 📑

分詞

現在分詞（doing）と過去分詞（done）の形容詞的用法。後置修飾。

中学3年 ❓❓

間接疑問

「〜かどうか」「〜か知っていますか」疑問文が文中に入る構文。

中学3年 🔗👤

関係代名詞

who, which, that で名詞を説明。主格・目的格の使い分け。

中学3年 🎭

仮定法

「もし〜なら」仮定法過去。現実と違うことを仮定する表現。

中学3年 🔄🎯

原形不定詞

let, make, have + 人 + 動詞の原形。「〜させる」使役表現。

中学3年
