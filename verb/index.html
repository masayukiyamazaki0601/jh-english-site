不規則動詞の覚え方

💡 パターンで覚えると簡単！

不規則動詞は以下のパターンに分類すると覚えやすいです。

ABA型（原形＝過去分詞）

come→came→come / run→ran→run / become→became→become

ABC型（3つとも違う）

go→went→gone / eat→ate→eaten / write→wrote→written / speak→spoke→spoken / take→took→taken

AAA型（全部同じ）

put→put→put / cut→cut→cut / read→read→read / let→let→let / set→set→set

ABB型（過去形＝過去分詞）【最も多い】

buy→bought→bought / think→thought→thought / have→had→had / make→made→made / say→said→said / tell→told→told / sell→sold→sold / find→found→found / get→got→got
