助動詞

中学英語の助動詞をわかりやすく解説します。このページで基礎から応用まで完全マスターしましょう。

📑 このページで学ぶこと

  1. 助動詞とは
  2. must / have to（義務）
  3. must not / don't have to（禁止・不要）
  4. may（許可）・should（助言）
  5. よくある間違い

助動詞とは

助動詞（じょどうし）は動詞の前に置いて、意味を付け加える言葉です。助動詞のあとは必ず動詞の原形になります。

【公式】 助動詞 + 動詞の原形
can（できる）/ must（しなければならない）/ may（してもよい）/ should（すべき）

must / have to（義務）

助動詞意味例
must〜しなければならないYou must study harder.
have to〜しなければならないI have to go now.

💡 must vs have to

must = 話し手の強い意志・義務（自分でそう思う）
have to = 外部のルール・状況（仕方なく）

must not / don't have to（禁止・不要）

表現意味例
must not〜してはいけない（禁止）You must not run here.
don't have to〜する必要はない（不要）You don't have to go.
超重要！ must not = 禁止（絶対ダメ）/ don't have to = 必要ない（やらなくてもOK）。全く別の意味！

may（許可）・should（助言）

  • May I come in? （入ってもいいですか？）
  • May I use your phone? （電話を使ってもいいですか？）
  • You should rest. （休むべきです）
  • We should help each other. （お互いに助け合うべきです）
  • You should not eat too much. （食べ過ぎるべきではありません）

よくある間違い

⚠️ よくある間違い

  • 「must」と「have to」の混同 → must = 話し手の意志、have to = 外部のルール。
  • 「must not」と「don't have to」の混同 → must not = 禁止、don't have to = 必要ない。
  • 助動詞のあとに to をつける → must to go は間違い。must go が正解。

  1. You ( ) study harder.
    → 答え: must
  2. I ( ) to go now.
    → 答え: have

    → 答え: has
  4. ( ) I come in?
    → 答え: May
  5. You ( ) not run here.
    → 答え: must

助動詞の実戦練習

A: May I use your phone?
B: Sure, you may.
A: I must finish my homework by tomorrow.
B: You should start now. Don't wait until the last minute.
A: You're right. I'll start right now.

助動詞の過去形

現在過去例（過去）
cancouldI could swim when I was five.
musthad toI had to go home early yesterday.
maymightIt might rain tomorrow.
willwouldI thought it would rain.
shallshouldI should have studied harder.
