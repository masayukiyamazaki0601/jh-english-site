仮定法

仮定法過去

「もし〜なら（実際は違うけど）」現実と違うことを仮定する。関係代名詞などの文法をマスターしてから挑戦しよう。

【公式】 If + 主語 + 過去形 + 〜, 主語 + would/could + 動詞の原形

  • If I were you, I would go there.（もし私があなたなら、そこに行くのに） ← 実際はあなたではない
Check! 仮定法では be動詞は常に were を使う（主語が I でも were）。

💡 ポイントまとめ

  • 仮定法過去：「もし〜なら（実際は違う）」
  • If + 過去形, 主語 + would/could + 動詞の原形
  • be動詞は常に were（I でも were）
  • 現実と違うことを仮定するときに使う

⚠️ よくある間違い

  • 仮定法で「If I was you」としない。仮定法では常に were を使う。「If I were you」が正しい。

📝 実践的な例文

  • If I were you, I would go there. （もし私があなたなら、そこに行くのに）
  • If I had money, I would buy a car. （もしお金があれば、車を買うのに）
  • If it were sunny, we could go out. （もし晴れていれば、外出できるのに）

💡 仮定法をマスターするコツ

仮定法過去＝現実と違うことを仮定する。be動詞は主語がIでもwereを使う。would/could + 動詞の原形とセットで覚えましょう。

⚠️ よくある間違い

  • 「If I was you」 → 仮定法では「If I were you」が正解。
  • wouldのあとにtoをつけてしまう → would + 動詞の原形。would to go は間違い。

📝 実践的な例文

  • If I were a bird, I could fly to you. （もし鳥なら、あなたのところに飛んでいけるのに）
  • If she had more time, she would learn piano. （もっと時間があれば、ピアノを学ぶのに）
  • If it were not rainy, we could go hiking. （雨でなければ、ハイキングに行けるのに）
  • I would be happy if I could meet her. （彼女に会えるなら幸せなのに）

💡 仮定法の基本形

If + 主語 + 過去形（were）〜, 主語 + would/could + 動詞の原形
例）If I were you, I would study harder.

💡 仮定法と条件文（if + 現在形）の違い

条件文（if + 現在形）：現実に起こりうる条件。If it rains, I will stay home.（雨が降れば家にいる）
仮定法（if + 過去形）：現実と違う仮定。If it rained, I would stay home.（もし雨が降れば家にいるのに ← 実際は降っていない）

⚠️ よくある間違い

  • 条件文と仮定法の混同 → 現実にあり得るなら条件文、あり得ない・違うなら仮定法。
  • wouldのあとにtoをつける → would + 動詞の原形。would to go は間違い。
