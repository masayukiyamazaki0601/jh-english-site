数量詞（many, much, a lot of など）

中学英語の数量詞（many, much, a lot of など）をわかりやすく解説します。このページで基礎から応用まで完全マスターしましょう。

📑 このページで学ぶこと

  1. 数量詞とは
  2. many / much / a lot of
  3. few / a few / little / a little
  4. some / any
  5. よくある間違い

数量詞とは

数量詞（すうりょうし）は、ものの「量」や「数」を表す言葉です。可算名詞（数えられる名詞）と不可算名詞（数えられない名詞）で使える数量詞が異なります。

可算名詞（数えられる）：book, cat, apple, student
不可算名詞（数えられない）：water, money, information, time

many / much / a lot of

数量詞意味使える名詞例
manyたくさんの可算名詞many books, many students
muchたくさんの不可算名詞much water, much money
a lot of / lots ofたくさんの両方OKa lot of people / water
  • There are many books on the desk. （机の上にたくさんの本がある）
  • I don't have much money. （あまりお金を持っていない）
  • There are a lot of people in the park. （公園にたくさんの人がいる）
注意！ much は否定文・疑問文でよく使われる。肯定文では a lot of のほうが自然。

few / a few / little / a little

数量詞意味ニュアンス名詞の種類例
fewほとんどない否定的可算few friends
a fewいくつかある肯定的可算a few friends
littleほとんどない否定的不可算little water
a little少しある肯定的不可算a little water

💡 few / a few の覚え方

a few = a がある = 肯定的（いくつかある）
few = a がない = 否定的（ほとんどない）

some / any

単語使う文例
some肯定文・勧誘の疑問文I have some friends. / Would you like some coffee?
any疑問文・否定文Do you have any questions? / I don't have any money.

よくある間違い

⚠️ よくある間違い

  • 「many water」 → water は不可算名詞。many は可算名詞専用。「much water」が正解。
  • 「much books」 → books は可算名詞。「many books」が正解。
  • few と a few の混同 → few = ほとんどない（否定）、a few = いくつかある（肯定）。

✏️ Practice！ 練習問題

以下の問題を解いて、理解を確認しましょう。

  1. There are ( ) books on the desk.
    → 答え: many
  2. I don't have ( ) money.
    → 答え: much
  3. He has ( ) friends. (almost none)
    → 答え: few
  4. I have ( ) friends. (some)
    → 答え: a few
  5. There is ( ) water left. (almost none)
    → 答え: little

📌 重要ポイント暗記カード

覚えること補足
many + 可算名詞many books
much + 不可算名詞much water
a few = 肯定的 / few = 否定的いくつかある vs ほとんどない

数量詞の実戦練習

A: How many books do you have?
B: I have a few books. Not many.
A: How much money do you have?
B: I have a little money. But not enough to buy that.
A: Do you have any questions?
B: Yes, I have some questions.

可算名詞 vs 不可算名詞 リスト

可算名詞（数えられる）不可算名詞（数えられない）
book / bookswater（水）
cat / catsmoney（お金）
apple / applesinformation（情報）
student / studentstime（時間）
idea / ideasnews（ニュース）
friend / friendsadvice（アドバイス）

数量詞のテスト対策

many + 可算名詞 / much + 不可算名詞 の区別が最頻出！

✏️ 穴埋め問題：
(1) How ( ) books do you have? → many
(2) I don't have ( ) money. → much
(3) He has ( ) friends.（ほとんどいない）→ few
(4) I have ( ) friends.（数人いる）→ a few
