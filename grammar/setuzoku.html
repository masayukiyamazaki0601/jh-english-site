接続詞

中学英語の接続詞をわかりやすく解説します。このページで基礎から応用まで完全マスターしましょう。

📑 このページで学ぶこと

  1. 接続詞とは
  2. and / but / because の使い方
  3. when / if / that の使い方
  4. because と so の注意点
  5. よくある間違い

接続詞とは

接続詞（せつぞくし）は、文と文（または単語と単語）をつなぐ役割をします。

接続詞意味役割
and〜と、そして並列・追加
butしかし逆接
becauseなぜなら理由
soなので結果
when〜するとき時
ifもし〜なら条件
that〜ということ内容

and / but / because の使い方

  • I like cats and dogs. （猫と犬が好きです）
  • I like cats but I don't like dogs. （猫は好きですが犬は好きではありません）
  • I am happy because I got a present. （プレゼントをもらったので嬉しいです）
  • I was tired, so I went to bed. （疲れたので寝ました）

when / if / that の使い方

  • Call me when you arrive. （着いたら電話してください）
  • If it rains, I will stay home. （雨が降れば家にいます）
  • I think that he is kind. （彼は親切だと思います）
  • I know that she is honest. （彼女が正直だと知っています）

because と so の注意点

重要！ because と so は同時に使えません。
「Because it rained, so I stayed home.」→ 間違い！
「Because it rained, I stayed home.」または「It rained, so I stayed home.」が正解。

よくある間違い

⚠️ よくある間違い

  • because と so の重複 → どちらか一方だけ使う。
  • 接続詞のあとの語順 → if, when, because のあとは通常の語順（疑問文ではない）。
  • 「I think he is kind.」の that 省略 → that は会話ではよく省略される。「I think he is kind.」でOK。

  1. I like cats ( ) dogs.
    → 答え: and
  2. I like cats ( ) I don't like dogs.
    → 答え: but
  3. I am happy ( ) I got a present.
    → 答え: because
  4. I was tired, ( ) I went to bed.
    → 答え: so
  5. Call me ( ) you arrive.
    → 答え: when

📌 重要ポイント暗記カード

覚えること補足
and = 並列「〜と」I like cats and dogs.
but = 逆接「しかし」I like cats but not dogs.
because = 理由「なぜなら」I am happy because I got a present.

接続詞 that の省略

think, know, say, believe などの動詞の後ろで使う that は、会話ではよく省略されます。

  • I think (that) he is kind.
  • I know (that) she is right.
  • He said (that) he was tired.
  • She believes (that) it is true.
テストでは：that があってもなくても正解です。ただし、フォーマルな文章では that を入れた方が良いとされています。

if の条件と「〜かどうか」の違い

if の用法意味例
条件もし〜ならIf it rains, I will stay home.
「〜かどうか」〜かどうかI don't know if he is kind.

because / so の使い分け問題

  1. ( ) it was raining, I took an umbrella. → Because
  2. It was raining, ( ) I took an umbrella. → so
  3. ( ) I was tired, I went to bed early. → Because
  4. I was tired, ( ) I went to bed early. → so
重要ルール！ because = 理由（なぜなら）、so = 結果（なので）。同じ文の中で両方は使えません。

接続詞 重要ルール一覧

  1. and = 並列：同じ種類のものをくっつける
  2. but = 逆接：反対のことをくっつける
  3. because = 理由：原因や理由を説明する
  4. so = 結果：結果や結論を述べる
  5. when = 時：時間や状況を表す
  6. if = 条件：仮定や条件を表す
  7. that = 内容：思ったことや言ったこと

接続詞 重要表現まとめ

接続詞意味例文
and〜とI like cats and dogs.
butしかしI like cats but not dogs.
becauseなぜならI am happy because I got a present.
soなのでI was tired, so I went to bed.
when〜するときCall me when you arrive.
ifもし〜ならIf it rains, I will stay home.
that〜ということI think that he is kind.

  1. ( ) it was raining, I took an umbrella. → Because

  3. ( ) I was tired, I went to bed early. → Because

  5. ( ) she studied hard, she passed the exam. → Because
  6. She studied hard, ( ) she passed the exam. → so

接続詞 重要構文 追加

both A and B（AとBの両方）: I like both cats and dogs.

not only A but also B（AだけでなくBも）: She speaks not only English but also French.

either A or B（AかBのどちらか）: You can have either coffee or tea.

neither A nor B（AもBもない）: I like neither coffee nor tea.

接続詞 テスト対策 重要ポイント

  • because + 理由 / so + 結果（同時に使わない！）
  • when = 「〜するとき」一点の動作
  • if = 「もし〜なら」条件
  • that = 「〜ということ」（think, know, say, believeの後ろでよく使う）
  • 接続詞 + 主語 + 動詞 の完全な文が後ろにくる
