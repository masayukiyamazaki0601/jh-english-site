there is 構文

中学英語のthere is 構文をわかりやすく解説します。このページで基礎から応用まで完全マスターしましょう。

there is 構文とは

「〜がある/いる」という存在を表す構文です。日本語の「机の上に本があります」のような表現に使います。

【公式】 There is/are + 名詞 + 場所
「〜に…がある/いる」

注意！ 日本語の語順と逆です。日本語は「場所 + に + 物 + がある」、英語は「There is + 物 + 場所」。

単数と複数の使い分け

名詞の数be動詞例
単数名詞There isThere is a cat under the table.
複数名詞There areThere are many books on the desk.
不可算名詞There isThere is some water in the glass.
数えられない物There isThere is a lot of traffic.
  • There is a pen on the desk. （机の上にペンがあります）
  • There are three apples in the basket. （かごの中に3つのリンゴがあります）

否定文・疑問文

  • There is not any milk in the fridge. （冷蔵庫に牛乳はありません）
  • Is there a hospital near here? （この近くに病院はありますか？）
  • Are there any students in the room? （部屋に学生はいますか？）
  • How many books are there on the desk? （机の上に何冊本がありますか？）

There is と It is の違い

There isIt is
役割「存在」を表す「それ」を指す
例1There is a cat.（猫がいる）It is a cat.（それは猫です）
例2There is a book on the desk.（本がある）It is on the desk.（それは机の上にある）

よくある間違い

⚠️ よくある間違い

  • 「There has a cat.」 → there構文は have ではなく、There is/are。
  • 「There is many people.」 → people は複数なので「There are many people.」。
  • there と it を混同 → 「There is a book.」= 本が存在する / 「It is a book.」= それは本だ。

there is 構文の応用

there is 構文は疑問詞と組み合わせて様々な質問ができます。

  • How many + 名詞 + are there?：How many students are there in your class?
  • What is there + 場所?：What is there in the box?
  • Is there anything + 形容詞?：Is there anything interesting in the news?

there is と there are の使い分け「近接の法則」

重要ルール！ There + be動詞 の be動詞は「すぐ後ろの名詞」に合わせます。複数のものがあっても、最初の名詞が単数なら is を使います。
There is a pen and three books on the desk.（最初の a pen が単数なので is）
There are three books and a pen on the desk.（最初の three books が複数なので are）

there is構文のテスト対策

テストでよく出る問題：

  • There is + 単数名詞 / There are + 複数名詞
  • 否定：There is not / There are not
  • 疑問：Is there〜？ / Are there〜？
  • How many + 名詞 + are there〜？

There is 構文の注意ポイント

  • 日本語と語順が逆：日本語は「場所 + に + 物 + がある」、英語は「There is + 物 + 場所」
  • there は「そこ」という意味ではない：There is a book. = 「本があります」（「そこ」ではない）
  • be動詞は後ろの名詞で決まる：近接の法則（後ろの名詞が単数なら is、複数なら are）

there is構文 応用表現

There used to be + 名詞（昔は〜があった）

  • There used to be a temple here.（昔ここにお寺がありました）
  • There used to be a park near my house.（昔私の家の近くに公園がありました）

There seems to be + 名詞（〜があるように見える）

  • There seems to be a problem.（問題があるようです）
  • There seems to be a mistake in this sentence.（この文に間違いがあるようです）

There happen to be + 名詞（たまたま〜がいる）

  • There happened to be a doctor on the train.（たまたま電車の中に医者がいました）

there is構文 疑問文 全パターン

  • Is there 〜?: Is there a pen on the desk?
  • Are there 〜?: Are there any students in the room?
  • How many 〜 are there?: How many students are there in your class?
  • What is there 〜?: What is there in the box?
  • Is there anything 〜?: Is there anything I can do?
