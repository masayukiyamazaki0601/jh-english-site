there is 構文

there is / are の意味

「〜がある・いる」という存在を表す。be動詞の仲間。

【公式】 There is + 単数名詞 + 場所
There are + 複数名詞 + 場所

  • There is a cat under the table.（テーブルの下に猫がいます）
  • There are many books on the desk.（机の上にたくさんの本があります）

💡 ポイントまとめ

  • There is + 単数名詞 / There are + 複数名詞
  • 否定文：There is not (isn't) / There are not (aren't)
  • 疑問文：Is there〜? / Are there〜?

⚠️ よくある間違い

  • 「There is」のあとに複数名詞を置かない。「There is many books.」→「There are many books.」

📝 実践的な例文

  • There is a cat under the table. （テーブルの下に猫がいます）
  • There are many books on the desk. （机の上にたくさんの本があります）
  • Is there a hospital near here? （この近くに病院はありますか？）
  • There is not any milk in the fridge. （冷蔵庫に牛乳はありません）

💡 there is 構文をマスターするコツ

There is/are + 名詞 + 場所。日本語の「〜に〜がある/いる」を表します。名詞が単数ならis、複数ならareを使います。

⚠️ よくある間違い

  • 「There has a cat.」 → there構文は have ではなく、There is/are を使います。
  • 名詞の数とbe動詞の不一致 → 単数名詞には is、複数名詞には are。

📝 実践的な例文

  • There is a park near my house. （私の家の近くに公園があります）
  • There are many stars in the sky. （空にたくさんの星があります）
  • Is there a convenience store around here? （この辺りにコンビニはありますか？）
  • There was a big earthquake last year. （去年大きな地震がありました）

💡 there is/are の時制変化

現在：There is/are / 過去：There was/were / 未来：There will be / 現在完了：There have/has been
There will be a concert next week.（来週コンサートがあります）

⚠️ よくある間違い

  • 「There has a book.」 → there + have は間違い。There is/are が正解。
  • 複数なのに is を使ってしまう → 「There is many people.」は間違い。「There are many people.」が正解。
  • There is と It is の混同 → 「〜がある」は There is / 「それは〜だ」は It is。
